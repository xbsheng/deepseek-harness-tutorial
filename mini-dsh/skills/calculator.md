# 计算器技能

当用户要求做数学计算时,使用本技能:

1. 把用户的算式转换成安全的 JavaScript 表达式(只允许数字、运算符、括号、小数点)。
2. 用以下命令执行并读取输出:

```bash
node -e "console.log(<表达式>)"
```

3. 把输出作为最终答案,并附上简要说明(结果、单位、保留两位小数)。

安全规则:绝不把用户输入直接拼进 shell 命令,必须先校验字符集:
只允许 `0-9 + - * / ( ) . %`。
